# 저작권 및 이용 안내<br><br>
본 저장소(Repository)에 포함된 모든 콘텐츠 — 소스코드, 이미지, 텍스트, 디자인 자산을 포함하되 이에 한정되지 않음 — 에 대한 저작권 및 모든 권리는 커뮤니케이션다움에 있습니다.<br>
본 저장소는 포트폴리오 열람 및 참고 목적으로 공개되어 있으며, 저작권자의 사전 서면 동의 없이 다음 행위를 금지합니다.<br>
<br><br>
**- 콘텐츠의 전체 또는 일부를 무단으로 복제, 배포, 게시, 2차 가공하는 행위**<br>
**- 상업적 목적으로 이용하는 행위**<br>
**- 출처를 밝히지 않고 자신의 창작물처럼 게시하는 행위**<br>
<br><br>
위 사항을 위반할 경우, 저작권법 등 관련 법령에 따라 민형사상 법적 책임을 물을 수 있습니다.<br>
